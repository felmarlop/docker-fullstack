# Frontend

Vue 3 frontend for the Docker Fullstack Boilerplate.

## Tech Stack

- Vue 3
- Vite
- Vuetify
- Material Design Icons
- ESLint
- Prettier
- pnpm

## Development

The frontend is started automatically as part of the full stack:

```bash
make start
```

## Commands

```bash
make frontend-lint      # Check linting and formatting
make frontend-lint-fix  # Fix linting and formatting issues
```
